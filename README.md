## 🌟 Overview
**GastroSense AI** is a state-of-the-art digital culinary operating system that
bridges volatile aroma chemistry, organoleptic receptor modeling, automated
safety compliance, and haute cuisine aesthetics.

Rather than guessing ingredient combinations, GastroSense AI evaluates
**shared volatile organic compounds (VOCs)** using cosine vector affinity,
computes dynamic 6-axis taste equilibria to prevent palate fatigue, projects
kitchen unit economics, and provides an interactive digital plating canvas
anchored in the Golden Ratio ($\Phi \approx 1.618$).

---

## ✨ Core Innovations

### 1. Molecular Volatiles Network Graph
- Maps 8 key chemical classes: Pyrazines, Terpenes, Esters, Lactones, Aldehydes,
  Phenols, Sulfur compounds, and Amines.
- Real-time HTML5 Canvas spring-physics simulation illustrating aromatic bonds.

### 2. 6-Axis Organoleptic Hexagon Radar
- Analyzes taste receptor stimulation: Sweet, Salty, Sour, Bitter, Umami,
  and Kokumi.
- Calculates Harmonic Balance Index ($HBI$) and raises Palate Fatigue warnings
  when single sensations overwhelm the palate.

### 3. Autonomous Molecular Recipe Architect
- Generates conceptual narratives, molecular cooking parameters (reverse
  spherification, precision sous-vide, fluid gels, cryo-shatter), thermal curves,
  and neuro-sommelier wine recommendations.

### 4. Interactive Slate Plating Studio
- Digital canvas with Volcanic Basalt Slate, Limoges Porcelain, and Smoked Glass.
- Draggable culinary elements (gel swipes, spheres, botanical herbs).
- Interactive Golden Ratio logarithmic spiral overlay.

### 5. EU 14 Mandatory Allergen Matrix
- Real-time tracking against European Regulation (EU) No 1169/2011 to safeguard
  guest health and prevent kitchen cross-contamination.

### 6. Kitchen Unit Economics & Menu Engineering
- Computes portion costs with trim-waste factors, target food cost percentage
  (28% benchmark), and classifies dishes into Stars, Plowhorses, or Puzzles.

### 7. Instant Command Palette (`Ctrl + K`)
- High-velocity keyboard workflow for busy kitchens and pass stations.

## 🚀 Quick Start

### Prerequisites
- Node.js >= 18.0.0 (Native ESM test runner)

### Installation & Verification
```bash
# Clone the repository
git clone https://github.com/ClaudioCeppi83/gastrosense-ai.git
cd gastrosense-ai

# Run 100% automated test suite
npm test

# Run code style compliance check (tabs, <=80 char lines)
npm run check-style

# Start local preview server
npm start
```
Then open `http://localhost:3000` in your browser.

## ☁️ Google Cloud & Firebase Architecture
- **Firebase Hosting:** Configured via `firebase.json` with aggressive caching
  and security headers (`X-Frame-Options`, `X-Content-Type-Options`).
- **Cloud Firestore:** Secured by declarative `firestore.rules` audited via
  Firebase MCP.
- **Cloud Storage:** Media bucket isolation configured in `storage.rules`.

Deploy in one command:
```bash
npx firebase deploy
```
