# GastroSense AI - Design System (DESIGN.md)

## 1. Aesthetic Philosophy: Avant-Garde Dark Luxury
The visual identity fuses fine dining minimalism (think Noma, El Celler de Can
Roca, Alchemist) with deep molecular laboratory precision. It avoids generic
tech gradients, opting for rich obsidian glassmorphism, gold accents, and
chromatic spectrum indicators.

## 2. Color Palette & Tokens
- Background Base: `#0a0b0e` (Deep Obsidian)
- Background Surface: `rgba(18, 20, 26, 0.75)` (Frosted Smoked Quartz)
- Card Border: `rgba(255, 255, 255, 0.08)`
- Accent Primary: `#e5a950` (Aromatics Gold / Maillard Amber)
- Accent Secondary: `#4ecdc4` (Cryo Mint / Herb Chlorophyll)
- Accent Violet: `#9b5de5` (Anthocyanin Essence)
- Text Primary: `#f7f8f9` (Porcelain White)
- Text Muted: `#8e95a5` (Basalt Gray)

## 3. Typography
- Primary Display & Headings: `'Outfit', 'Cinzel', serif / sans-serif`
- Technical & Data Readouts: `'JetBrains Mono', monospace`
- Body Text: `'Inter', -apple-system, sans-serif`

## 4. UI Architecture & Micro-Interactions
- Glassmorphism backdrop filters: `backdrop-filter: blur(16px)`
- Spring physics animations on network graph nodes.
- Radar chart pulse animation on sensory equilibrium change.
- Plating studio drag-and-drop handles with subtle drop shadows.
- Keyboard navigation indicator: glowing gold outline with `2px solid #e5a950`.
